# Project Overview

The Modular Scouting Quadcopter Prototype is a compact UAV hardware integration platform focused on embedded sensor testing, rapid prototyping, flight-controller configuration, Raspberry Pi compute, 3D printed mounts, wiring verification, and test validation.

The project is being developed as a modular quadcopter platform for scouting, inspection, and future autonomous sensing applications. The current build integrates a SpeedyBee F405 V4 flight controller, Raspberry Pi 5 onboard compute, LiDAR/range sensing, optical-flow sensing, camera modules, telemetry hardware, power distribution, and 3D printed PLA/PETG components.

The main objective is to build practical aerospace hardware experience in system integration, embedded interfaces, rapid prototyping, wiring, sensor testing, and flight-readiness validation.
