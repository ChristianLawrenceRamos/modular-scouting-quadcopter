# Build Log

## Rev A — Initial Hardware Layout

### Goal
Create the first physical electronics layout for the scouting quadcopter.

### Work Completed
- Mounted flight controller and ESC stack.
- Planned Raspberry Pi 5 placement.
- Identified sensor locations for LiDAR, optical flow, and camera modules.
- Began wire routing and connector planning.

### Issues Found
- Sensor placement required more clearance.
- Wiring layout needed better separation between power and signal lines.
- Mounting-hole alignment required additional fit checks.

### Changes for Next Revision
- Redesign sensor mounts.
- Improve wire routing.
- Add caliper-based dimensional checks before reprinting parts.
